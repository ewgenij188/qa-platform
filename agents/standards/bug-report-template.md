# Bug Report Template

## Title

Short clear summary.

Example:

Unable to save user profile after updating email.

---

## Severity

| Level | Definition |
|---|---|
| **Blocker** | System is down; no workaround; blocks all testing |
| **Critical** | Core feature broken; no workaround; affects production users |
| **Major** | Feature broken but workaround exists; significant impact |
| **Minor** | Cosmetic issue, edge case; low user impact |
| **Trivial** | Typo, alignment, minor visual glitch |

---

## Priority

| Level | Definition |
|---|---|
| **Highest** | Must fix immediately; release blocker |
| **High** | Fix before current release |
| **Medium** | Fix in next sprint |
| **Low** | Backlog; fix when capacity allows |
