# UI Testing Standard

## Main Areas

Validate:

- Functionality
- Usability
- Accessibility
- Responsiveness

---

# UI Assertions

Verify:

- Element visibility
- Element state
- Text values
- Error messages
- Navigation

---

# Forms

For each form verify:

Positive cases:
- Valid input

Negative cases:
- Empty values
- Invalid values
- Boundary values

---

# Tables

Verify:

- Sorting
- Filtering
- Pagination
- Data integrity

---

# Navigation

Verify:

- Menu links
- Redirects
- Deep links
- Browser navigation

---

# Accessibility

Basic checks:

- Visible labels
- Keyboard navigation
- Contrast issues
- Focus indicators

---

# Browser Coverage

Minimum:

- Chrome
- Firefox

Optional:

- Edge
- Safari
