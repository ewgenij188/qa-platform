# Jira Workflow Standard

## Story Analysis

For every story:

1. Read requirements
2. Identify gaps
3. Identify risks
4. Identify dependencies
5. Identify test scenarios

---

# QA Checklist

Before testing:

- Requirements reviewed
- Acceptance criteria reviewed
- Test data prepared

During testing:

- Positive testing
- Negative testing
- Edge cases
- Exploratory testing

After testing:

- Evidence collected
- Defects reported
- Regression impact assessed

---

# Definition of Ready

Story contains:

- Description
- Acceptance criteria
- Scope
- Dependencies

---

# Definition of Done

- Acceptance criteria passed
- Critical defects resolved
- Regression completed
- Automation added if required
- Test evidence attached
